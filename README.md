# AI STARTIFY 2.0 — STARTUP ECOSYSTEM, INVESTORS, GAMIFICATION & AI MENTOR

> **Mission**: *Give Every Student a Chance to Build Something Real.*

AI Startify 2.0 — это полноценная экосистема нового поколения, объединяющая школьников-основателей, венчурных инвесторов, менторов, родителей, спонсоров и образовательные организации в единой технологической платформе.

---

## 🌟 Ключевые возможности и подсистемы

### 1. Единая ролевая матрица (6 ролей)
- **Student (Школьник / Основатель)**: Разработка стартапов, участие в Startup Jams, выполнение квестов Battle Pass, прокачка уровня, продвижение проекта за Quasar.
- **Investor (Инвестор / Венчур)**: Каталог школьных стартапов с фильтрацией по технологиям, школам и стадиям, аналитика Dev Score и активности коммитов, отправка запросов на знакомство и структурированных инвестиционных офферов (гранты, оборудование, менторинг).
- **Parent (Родитель)**: Отслеживание образовательного прогресса ребёнка, система семейных поощрений (*Parent Rewards*), верификация и подтверждение согласия на участие в конкурсах и получение денежных призов/грантов.
- **Sponsor / Organization (Спонсор)**: Проведение собственных Startup Jams с верифицированным эскроу призового фонда, выделение облачных ресурсов и инструментов.
- **Mentor (Ментор / Эксперт)**: Проведение клубных сессий, ревью кода, со-менторинг с AI.
- **Admin (Администратор)**: Полный аудит транзакций Quasar, проверка юридических статусов и модерация.

### 2. Внутренняя валюта Quasar & Кошелёк
- XP полностью заменён на **Quasar** — космическую utility-валюту платформы.
- Начисляется исключительно за полезные действия: коммиты, деплой прототипов, победы в джемах, выполнение ежедневных и недельных квестов.
- **100% Idempotent Audit Log**: Защита от накруток и повторных начислений. Каждая транзакция имеет уникальный `idempotencyKey`.
- **Startup Promotion Market**: Инвестируйте заработанный Quasar в продвижение своего проекта (Featured на главной витрине, Velocity Boost 2x, Category Spotlight, Discovery Top).

### 3. Startup Jams (Хакатоны и соревнования)
- Формат соревнований в духе itch.io, ориентированный на решение реальных вызовов Казахстана и мира.
- Организаторы создают джемы с верифицированным призовым фондом (например, 500 000 ₸).
- Прозрачная панель жюри с 6 критериями (Инновационность, Польза, Реализуемость, Прототип, Потенциал, Питч).
- **Режим слепого оценивания (Blind/Anonymous Judging)** для снижения предвзятости.
- Прозрачный журнал выплат с обязательным согласием родителей для несовершеннолетних участников.

### 4. Battle Pass Season 01 — «Build Your Future»
- 20 уровней с треками **Free** и **Founder Pass**.
- Ежедневные (Daily), Недельные (Weekly) и Специальные (Special) квесты.
- Награды: Quasar, уникальные бейджи, рамки аватара, титулы и скидки на продвижение. Без лутбоксов и азартных механик.

### 5. AI Mentor (Powered by NVIDIA NIM API)
- Интеграция с официальным **NVIDIA API** (`meta/llama-3.1-70b-instruct`) через `https://integrate.api.nvidia.com/`.
- 4 специализированных режима:
  - 💡 *Идея и Проверка (CustDev, валидация гипотез)*
  - 🛠️ *Архитектура и Код (YOLOv8, ONNX, микроконтроллеры, оптимизация)*
  - 📊 *Бизнес и Монетизация (Freemium, B2B, юнит-экономика)*
  - 🚀 *Питч и Инвесторы (Elevator pitch, подготовка к вопросам жюри)*
- **Agent Mode с подтверждением пользователя**: AI Ментор предлагает конкретные действия (генерация README.md, создание GitHub Issue, подготовка заявки на джем) и выполняет их строго после нажатия «Одобрить и выполнить».

### 6. GitHub Workspace & Activity
- Подключение репозиториев к карточкам стартапов.
- Просмотр дерева файлов и рендеринг README.md.
- История коммитов, веток, открытых Pull Requests и Issues.
- Защита приватности: инвесторы не получают доступ к приватным репозиториям без явного разрешения команды.

### 7. Clubs & Communities (Клубы и сообщества)
- AI Club, Young Founders Guild, Robotics Lab.
- Публикации, обсуждения, обмен опытом, поиск сокомандников.
- Клубные привилегии: бонусные квесты, +20% к Quasar, закрытые сессии с экспертами.

### 8. Анонимный рейтинг (Anonymous Leaderboard)
- Переключатель режима: Публичный профиль / Анонимный режим.
- Автоматическая генерация научно-фантастических псевдонимов (`Quasar_4821`, `StarBuilder_192`).
- Полная защита персональных данных несовершеннолетних в общем рейтинге.

### 9. Мероприятия и программа Travel Grants
- Фестивали, Demo Days, выставки технологий.
- Программа **Travel Grants**: покрытие расходов на дорогу и проживание для школьников из регионов с подтверждением родителей.

### 10. Real Rewards & Resource Center
- Обмен Quasar на физические товары (худи AI Startify, Raspberry Pi 5 AI Kit, Apple iPad).
- Бесплатный доступ к облачным ресурсам: NVIDIA Inception Credits ($2,500), GitHub Student Pack ($200k value), Supabase Pro, Figma Education.

### 11. Мультиязычность
- Полная поддержка трёх языков интерфейса: **Русский (RU)**, **Казахский (KK)** и **Английский (EN)**.

## 🛠️ Технологический стек

- **Frontend & Fullstack**: Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS.
- **Иконки & Дизайн**: Lucide React, Sci-Fi Cyber Space Theme (`#05070f`, Quasar Cyan `#06b6d4`, Nova Purple `#a855f7`, Gold `#f59e0b`).
- **AI Core**: NVIDIA NIM API Client (`meta/llama-3.1-70b-instruct`) со смарт-фоллбэком.
- **Хранилище данных**: Транзакционная in-memory + персистентная база данных с защитой идемпотентности.

## 🚀 Запуск проекта

```bash
# 1. Установка зависимостей
npm install

# 2. Настройка переменных окружения в .env.local
NVIDIA_API_KEY=your-nvidia-nim-api-key
NVIDIA_MODEL=meta/llama-3.1-70b-instruct

# 3. Запуск локального сервера разработки
npm run dev
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).
